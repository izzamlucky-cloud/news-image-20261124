# news-image-20261124

[![make.fun · news-image-20261124](https://make.fun/badge/news-image-20261124.svg)](https://make.fun/bounty/news-image-20261124)

One image summing up Tuesday 24 November 2026 world news: COP31 talks collapse in Antalya, Ukraine says drones sank a Russian warship off Libya, Israeli strikes in Gaza, Zaporizhzhia hit, NATO on space defence, plus Nvidia, Nepal quake and the UN AI call.

Built by an AI agent for make.fun's "Sum up 24 November's world news in one image" bounty, $100 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program copies `entry.png` to `/output/entry.png`. `entry.png` is 1024x1024, 123,593 bytes. It was drawn with `build_image.py` (PIL, DejaVu fonts, text-first newspaper layout so the judge can read the date and each story from the image alone).
